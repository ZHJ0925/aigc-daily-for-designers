可灵 Kling 4.0 深度实测：30 秒一镜到底，复杂打斗和运镜更稳了

卡兹克烧了几万积分实测 Kling 4.0：重点看 30 秒直出、复杂打斗动态，以及全能参考的可控性；1080P 30 秒约 450 积分（会员价约 16 元），并建议用更便宜的 4.0 Flash 先打样再上正式版。

做广告或产品演示短片时：Flash 先跑分镜小样 → 关键帧锁定开场/高潮/结尾 → 正式版出片，能明显省积分。

Anatomy Skill：让 AI 把抽象原理做成可交互装置，再一键出科普视频

开源 Skill Anatomy 的理念是「物体本身就是解释」：Agent 会把机械表、发动机、显卡等做成可拆解的交互动画；卡兹克进一步让 AI 在其上配讲解与配音，几分钟即可生成结构化科普视频。

做产品原理/功能科普时，先用 Anatomy 出可交互模型，再补旁白成片；自己学习可用省额度模型，对外发布再上顶级模型抠细节。

Meta Muse 设计总监：做好 AI 产品设计的 5 个关键思路

Alex Cornell 分享 Muse 设计方法：把 AI 当人助理而非工具来想；思维过程用渐进披露，默认只显示「在干活」；模型够快就砍掉安抚等待的 UI；接受非确定性，搭骨架而不是控每一屏；用 Ideas/Feed 帮用户发现 Agent 还能做什么。

做 Agent 界面时先问：哪些信息是给工程师看的日志，哪些是给普通用户的一句话状态？能分层就别全铺在主对话里。

Browser Use 讲解：什么是浏览器智能体，什么时候该用它

Browser Use 拆解浏览器 Agent 的三件套（模型、Harness、浏览器）与「观察→决策→执行」循环；并给出选型：有 API 用 API，流程固定用脚本，下一步依赖判断再用 Agent，同时提醒结果校验、网站封锁与提示词注入风险。

给设计/运营自动化浏览器任务前，先画决策树：能调接口就别点网页；必须点网页时，把成功标准写成「可核对的页面状态」，不要只看 Agent 自称完成。

清华开源 PilotDeck 2.0：白盒记忆 + 智能路由，复杂任务成本约降到 1/6

清华 THUNLP 等开源智能体操作系统 PilotDeck 2.0：按 WorkSpace 隔离项目文件与记忆；记忆可查可改；支持后台常驻与 MCP；用「主强子弱」路由把规划交给强模型、执行交给轻量模型，官方称复杂任务成本可砍到约六分之一。

多项目并行时，给每个项目单独「工作舱」存规范与偏好，避免文案风和设计规范串台；贵模型只做决策，琐碎排版交给小模型。

产品经理用 AI 做好了 Demo，设计师如何重新拿回设计主动权？

面对评审会上已经能点能跳的 AI Demo，文章用小程序违规举报案例演示：先分清目标与手段，再把对话原型与表单方案放在同一任务下比较理解/填写/纠错成本，最终用「表单 + AI 辅助分类」替换多轮追问。

下次碰上「AI 已经搭好一版」，先列用户必须完成的 3 个任务，再问：当前路径是在帮用户，还是在增加等待与纠错？有对比方案更容易说服团队回头改。

Tangerine：拖住文件按一下键，轮盘菜单直接转格式

Mac 文件转换工具 Tangerine 的交互很克制：拖起文件后按 Shift 出轮盘选格式，Command/Control 切换工具与 AirDrop 等操作；轮盘跟着鼠标走，松手即完成，全程不用打开完整主窗口、也不打断整理文件的动线。

做效率工具时优先「嵌进现有动作」：选中→修饰键→就地完成，比再开一个大面板更符合整理文件时的心流。
