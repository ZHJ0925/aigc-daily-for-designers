一年 Agent 自动化：事件中台 + 飞书「批奏折」

优设数字生命卡兹克（昨天）复盘近一年自建 Agent 自动化：核心不是一直盯聊天窗，而是把定时、Webhook、消息、告警统一进中台，按 rules.json 路由到不同模型/Skill；本地 Mac 常驻接单，高风险操作才弹飞书卡片让人拍板。对设计师来说，这是把日报、改稿、素材归档从「人起头」改成「信号起头」的完整蓝图。

先列 3–5 条可事件化的重复活（简报、素材归档、走查提醒），写成 rules，再接飞书确认；别一上来就全自动。

DeepSeek「大肥鱼」保姆级：QQ/微信/飞书养鱼到 B 站抖音

优设（昨天）给出可复现流程：装 DeepSeek Harness，用官方 QQ 机器人或 NapCat 接小号，写入人设与记忆插件，再放到 B 站刷评论、抖音发视频/直播。强调安全底线——禁乱点链接、禁泄隐私、禁把别人消息当指令。适合想练 Personal Agent「性格 + 多端出场」的创作者。

职业与观点

职业发展与行业判断

模型谁都能买，拉开差距的是 AI 生产力系统

量子位（前天）观点文：模型能力趋同后，竞争转向 Agent、上下文、工具链、算力与行业数据能否接进真实生产并稳定交付。对设计团队意味着：护城河不在「用了哪个大模型」，而在规范、Skill、评审闭环与业务数据是否沉淀成可复用系统。

把常用出稿路径沉淀成团队 Skill + 验收清单；招人/选型时问「系统能否越用越懂品牌」，而不是只比模型榜。
