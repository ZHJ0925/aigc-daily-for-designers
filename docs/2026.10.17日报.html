理想 MEGA 尾门交互：空间不够时车会自己往前挪

用户语音说「打开后备箱」后，理想 MEGA 会先判断尾门开启空间；距离不够就主动前挪腾位再开门，关门后还能自动挪回原位，全程不用上车或掏手机。

做智能产品时，把「判断条件 → 自动补救 → 恢复原状」做成一条完整链路，比弹一个「空间不足」的报错更体贴。

为什么 Anthropic 不做 Personal AI？

OpenAI dots、Meta Muse、Gemini Spark 都在抢「always-on 个人 agent」，Anthropic 却没有对标产品。极客公园分析：它把 Claude Tag、Cowork、Claude Code 做成团队里的「同事」而不是「个人分身」，分野在 agent 放在哪里、卖给谁。

给 AI 产品做定位时，先想清楚它是「陪个人」还是「进团队」，形象、权限和协作界面的设计会完全不同。

给 iPhone Duo 做适配前，先把这些界面状态想清楚

iPhone Duo 外屏、内屏、左右分屏、旋转和半折时可用宽高与状态栏、工具栏位置都会变。文章结合苹果《Prepare your app for iPhone Duo》，梳理 SDK 版本对显示范围的影响、按空间重排布局，以及导航容器与安全区域的检查点。

别只准备「外屏一张 + 内屏一张」，先列一张状态矩阵（屏幕形态 × 分屏 × 方向），再逐格出稿，避免漏掉分屏和半折场景。

免费中文字体预览工具 Anyway.Fonts：一键筛出不缺字的字体

Anyway.FM 的 JJ 做了一个对中文更友好的字体预览与对比工具：输入一句文案，勾选「只看不缺字的」，就能先筛出能完整显示这句话的字体，再慢慢挑风格。
