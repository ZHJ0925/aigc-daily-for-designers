教程、工作流与 Prompt 落地

Figma 生图一次勾选 3 个模型：同一句提示词，对着结果选

优设细节猎人（昨天，11 月 19 日 23:49）龙爪槐守望者写到，在 Figma Design 的画布里，不论从零生图还是选中一张图做局部修改，都可以同时勾选最多三个不同的图像模型，例如 Nano Banana 2 Lite、Nano Banana 2 和 GPT Image 2.5 Sunburst。敲入同一句提示词后，系统会并行跑出多张不同风格和质感的结果供你挑选，选中满意的那张可以直接落进画布。以前常见的做法是生成不满意就改一遍提示词再抽一次，或者来回切换模型反复试错；这一下更接近设计工作里「先出几版飞机稿、摆在一起对比」的习惯。

与其在同一个模型里把提示词改十遍，不如先并列出几版不同气质的结果，选定后再往画布里精修。

先写 PRD 和 GUI 文档，再让 Fable 5.2 吐出一个能玩的 HTML 游戏

优设（昨天）实测 Claude Fable 5.2：作者只提了一句「做一个能玩的网页版游戏，不要素材包、不要外链，最后给我一个双击就能打开的 HTML 文件」，但没有立刻让它写代码，而是先让它出一份 PRD 和一份 GUI 设计文档，视觉和玩法定稿后才动手开发。实测做了三个方向：赛博霓虹赛车、武侠行镖 RPG，以及一段 50 秒、8 个镜头的自我介绍动效；旁边还放了上一轮用 Gemini 4 Argon 做的同题材霓虹机车作为对照。这三件加起来体积不到几百 KB，没有位图、字体包或外部音频，画面由代码绘制，声音用 WebAudio 现场算。RPG 能维持资源循环和成长曲线；介绍片里吉祥物「小寓」每镜一句，作者觉得是可以直接用的物料，而不只是演示。这和本周一收过的「一晚上搓出 12 关街机」不是同一组跟做，侧重点在可交互网页和文档先行。

先把玩法和视觉写成文档再让模型写代码，比一上来就要一个成品 HTML，更容易判断它到底有没有把规则做完整。

Agent 与编程实战

Agent 工作流与人机协作

别指望 Agent 画出漂亮视觉：先写 Skill，让它按组件库搭框架

优设 Clip 设计夹（昨天）刊出设计师 Ye_susu 的 Agent 提效实践。直接让 Figma Agent 指定组件库出稿，结果经常用错组件、擅自改名、分离实例，也不走文本样式和变量。作者没找到合适的现成方案，就自己写 Skill。第一套 design-system-use 用来约束组件用法，并把海外项目里的文本翻译、页面命名、画板尺寸、图层结构和自动布局习惯写进去——视觉仍低于及格线，但用来搭 B 端页面框架已经能省不少手活。图标方面，Figma Agent 不能编辑矢量路径，第三方 Agent 画出来也不怎么能用；于是改成 icon-generate：提供多个图标库，让 Agent 检索命中的 SVG 并按项目规范写入 Figma，作者再挑选和二次创意。限制也很清楚：库里多是线性和面性功能图标，复杂个性图标还得手绘；SVG 往往已经转曲，改圆角只能重绘。绘制页面流程这种「按交互稿把 UI 串起来」的工作，作者先做能力测试，再针对连线绕路的问题，用标注截图让 Agent 自己分类总结规则，写成 flow-connect。最后还尝试把整段需求设计做成 requirement-design Skill。作者的判断是：这套东西更适合偏组件和文字排版的 B 端；复杂任务要用更强的模型（文中用的是 5.6 Sol 高档及以上）；并且提醒频繁切换任务会很难进入心流。

先承认 Agent 的视觉还不靠谱，再把它限制在「按规范搭框架、检索图标、串流程」这些能用规则说清的步骤上；规则写不明白时，先标注截图让它自己归纳。

行业观察与设计师视角

微信给公众号加了 AI 摘要，创作者担心读者再也不点进原文

优设细节猎人（今天，11 月 20 日 0:31）龙爪槐守望者拆了微信「公众号」订阅列表里的新入口：顶部常看头像最左侧多了一个绿眼睛「AI 摘要」，点开后拉起「小微 AI 测试版」对话框，自动发出总结请求，几秒内把常看公众号的新文章收成两三句。产品意图是帮读者省掉筛选、把人拉回阅读；但站在创作者一侧，读者如果在对话窗里就把观点看完，原文阅读量和底部广告曝光都会被截走。微信的折中是在每段总结上方挂一张带封面的原文跳转卡片，想用摘要勾起好奇心，再把人导回文章。

给信息流加 AI 摘要前，先想清楚阅读和分发还靠不靠「点进原文」；如果靠，摘要旁边必须留一条足够明确的回原文路径，而不是把正文替换掉。

AI 工具与产品

新工具、模型与可用产品

Canva 出了「AI 开关」：大部分生成式功能能一键关掉

IT之家（昨天，11 月 19 日 21:01）报道，Canva（可画）宣布推出「AI 开关」，免费版和 Pro 版用户都可以统一关闭或开启绝大多数 AI 工具。打开后会移除大部分生成式功能，但「背景移除」「魔法抓取」这类 AI 驱动的图像编辑工具仍然保留。素材库里还可以打开「减少 AI」，降低搜索时碰到 AI 生成图像的概率。两项设置都在「个人资料」里调整；如果要管理整个平台的生成式 AI，则进入设置里的「权限」，找到「启用生成式 AI 功能」。

设计工具开始把「用不用 AI」做成总闸，而不只是一个个功能入口；如果团队或客户不希望稿件带上生成痕迹，先确认总开关和素材库过滤分别管到哪一层。
