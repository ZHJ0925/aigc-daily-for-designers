WorkBuddy 保姆级教程：60 条提示词覆盖 7 大办公场景

优设（昨天）看到 WorkBuddy 全平台月活已破 3235 万，可不少人装了却还在对桌面智能体说一句「帮我写周报」。文章整理了 60 条可直接复制的提示词，覆盖本地文件整理、内容创作、多 Agent 流水线、需求沟通、项目排期、会议评审和知识沉淀七类高频场景。开篇先强调写进自定义指令的安全绳：缺信息就列待补清单、严禁编造数据；凡是对外发送、新建、修改或删除系统记录，必须先输出预览和影响范围，等你明确点头再执行。派活则用五步公式——划定范围、规定动作、补上细节、设定红线、先出预览。

先把「不编数据、改删先确认」写进自定义指令，再按卡住的环节去复制提示词；范围和红线写清楚，比再堆十条空泛指令更管用。

大厂 AI 场景

平台与大厂产品动向

国行苹果 AI 来了：18 项功能上线，唯独缺了新版 Siri

优设（昨天）梳理国行 Apple 智能：11 月 4 日开发者可测，12 月随 iOS 27.3 推送给普通用户，但公告写明「本次更新不包含 Siri AI」。第一批是写作润色、通知摘要、照片消除、一对一通话实时翻译、视觉智能等嵌在系统里的工具；复杂问答可手动打开通义千问扩展，每次把问题或图片转出去都会先弹窗确认。和海外能把短信、邮件、待办串起来办事的新版 Siri 不同，国行目前还是一个个单独工具。文章也对比了安卓和国产手机已能叫车、找取件码的进度，并提醒：真要让 AI 替你翻邮件、改日历，不能只弹一个「是否确认」，得让人看清它读了哪封邮件、已经做了哪几步。

别按海外发布会演示去期待国行第一批；先看翻译、摘要、润色和照片消除能不能少切几次 App，跨应用办事还得等新版 Siri 和国内 App 开放接口。

案例灵感

可借鉴的产品与设计细节

Figma 换上 Hello Kitty 光标，同事在画板里抢着点赞

优设猎人（今天）注意到 Figma 和三丽鸥联名：FigJam 里可以选 12 个角色当光标，便利贴、胶带、贴纸全部换成对应主题，连加载页也换了皮肤。企业级软件不必从头到尾保持冷静严肃——白板的核心任务恰恰是激发灵感和发散思维。这套可爱主题能直接点燃玩心，让人更愿意移动鼠标、在画板上扎堆互动。

协作白板可以故意做得好玩一点：主题光标和贴纸降低开口成本，往往比再加一条「请积极发言」更有效。

Agent 与编程实战

Agent 工作流与人机协作

千问办公 2.0：把 Agent 带进工作群的 Team Agent

量子位（昨天）：千问办公上线三个月来最大一次升级，推出所谓行业首个支持多人与 Agent 协作的「协作」能力。用户可以组建团队和数字员工共同工作的协作空间，实时关联多个钉钉群聊、文档、AI 表格和听记，由数字员工梳理进展、总结共识并创建、跟进待办。「人机共创」打通对话、预览和编辑，可在对话框里边看文档边提意见，也能直接圈选段落、单元格或幻灯片一次提交修改。「自动任务」可订阅指定人的消息、群里 @自己或审批单，条件满足就开工；再配上资料空间，以及手机、电脑、网页三端同步，任务在云端执行，电脑关机后也能继续跑。

团队 Agent 好不好用，先看它能不能站在群聊和文档的现场里干活，而不是再开一个只有你自己能用的聊天窗。

职业与观点

职业发展与行业判断

VibeCoding 时代，UI 设计师要守住的 2 项核心能力

优设（昨天）回应「AI 写代码时顺手把界面也做了，设计是不是没了」：一人公司和多 Agent 编排在逻辑上成立，但越专业的领域越需要人来做决策和审查。作者认为设计师最有价值的不是操作软件，而是决定设计什么、设计成什么样，以及判断生成结果好不好。岗位职责会往上游产品细节和下游前端实现扩张，可核心门槛仍是产品思维和审美趣味。文中给新人画了四步：先打好 UI 基础并能自己动手改稿，同步拓宽审美，再用 VibeCoding 把想法做成能用的小产品，最后去理解技术实现原理。

AI 放大的是人与人之间的差距，不是抹平它。先练到能自己改稿、能说出「哪里不好」，再让模型去扩展你的手。

AI 工具与产品

可上手的工具与产品更新

即梦 Seedream 5.5：透明底直出，一张图能改 15 轮还不糊

优设情报（今天）实测即梦新一代图片模型 Seedream 5.5：提示词里写明「透明背景 / PNG 透明底 / Alpha 通道」，Y2K 贴纸、书法字甚至长毛猫的细碎飘毛都能比较干净地直出 PNG，半透明玻璃和水杯则还不稳。同一张图连续改 15 轮，未改区域基本纹丝不动，画质也看不出变糊，适合给虚拟人换发型，或从空房间一点一点「装修」。官方称密集小字准确率到 95%，作者拿高考数学卷和报纸细文对比 GPT Image 2，放大后少有乱码，但题目对不对仍要人核对。人像皮肤质感和实拍感也更接近真照片。

做贴纸、文字和需抠毛发的素材时先试直出透明底；改图一次只动一处，把多轮编辑当成造型或场景推演，而不是整张重抽。
