不用抽卡做绘本和科普视频：透明底素材加代码动效，角色还能沿用

优设网（昨天，11 月 24 日）阿真Irene 分享了两条自己整理的 Skill。起因是有家长觉得「又做视频又做网页、还要剪辑字幕」太折腾，希望一套流程既能出带字幕的视频，又能做互动问答网页。她先是想做记英语生词的动态互动页，后来发现同一套方法也能做科普和情景小剧场，于是收成两个 Skill：一个是把视频嵌进互动网页的「英语生词故事工作室」，一个是只出视频的「故事小剧场」。核心做法不是用 AI 视频工具抽卡，而是「静态透明底素材 + 代码动效渲染 + 自动音画对齐」直接出片——不烧视频积分，角色不容易崩，文字也更清晰，局部透视或细节不对，截图给 Agent 改就行。文案很长也能做完，生成好的角色设定图可以一直沿用，适合做系列故事或长篇科普。风格可自己描述，文章里示范了软线扁平、复古绘本、彩铅报刊漫画，还可以打开「逐笔分层」，让主要角色像一笔一笔被画出来。只做视频时，把脚本或自己录好的口播音频交给 Skill 即可，需要的话还能加背景音乐；做互动网页则是调用 Skill，再给课文或资料、要标成生词的词，确认文案和角色图后等渲染。生图和配音她更推荐 Antigravity 里的 Gemini 4 系列，其次是 Codex，因为都能直接出比较干净的透明底图；WorkBuddy 她测过做互动网页没问题。如果所用 Agent 不会出透明底，可以接 LibTV，或让 Agent 改接到已有的出图和音频工具。音频默认偏机械，建议改用 AI 音色或上传自己的口播，Skill 会做回听转录和音画对齐。文章末尾给出两个 GitHub 检索名：Azhen-Story-Theater、Azhen-Vocab-Story-Studio。原文里中文名和检索句的对应关系写得对调，用的时候两个都搜一下更稳。她也说，这种方式不如生成式视频生动，但更省钱省事，刚好碰到系列科普、绘本或口播配动态画面时用得上。

先把角色设定图定住再批量出镜，比每次重新抽视频更适合做系列；细节不对就截图改，不必整段重跑。

九个高审美生图 Skill：同一套工具，换一张层次清楚的照片，结果完全不同

优设网（昨天，11 月 24 日）AI星踪岛从艺术生收藏夹里扒了几十个 WorkBuddy 生图 Skill，实测翻车一多半，最后留下九个，覆盖纸雕、立体积木、慢门摄影感、杂志拼贴、半摄影半手绘跨页、复古印刷工艺、双色网点海报、旅行记忆标本和像素画。安装很简单：把网址贴进对话框让它装上，然后 /调用Skill，把照片拖进去。作者特别强调选图。纸雕旅行微缩（Papercraft Travel Diorama）第一次用普通店铺照，几乎还是写实，只有外轮廓有点纸雕味；换成主体明确、货架和街道层次清楚的街角杂货铺后，铁艺架子、叠好的旧 T 恤和角落酒瓶都被搬上了瓦楞纸板。立体积木（Isometric Healing Blocks）更适合形体和前后遮挡清楚的照片，台阶会变成圆润几何块，行人被捏成没有面孔的微缩手办。后面还有杂志拼贴 Editorial Fragments、半摄影半手绘跨页、能把同一张建筑照做成五种工艺的 Photo Press V1、Yan Liu 的 Mono Color 双色网点海报，以及像素画。文章也提到两个找 Skill 的站点：Skills.sh 看热门排行，SkillsMP 搜相对冷门的。电影感、杂志风和复古印刷都能做，但作者的经验是：同一套 Skill，只换一张层次更清楚的底图，效果会差出一截；没有鲜明主角或空间关系的照片，再好的风格也容易贴一层皮。

先为 Skill 挑「主体清楚、前后有层次」的底图，再谈风格；不要期望随便一张生活照都能做出微缩世界。

Muse 和豆包小豆：个人智能体开始把头像放到顶部居中

优设情报（约 8 小时前，猎人龙爪槐守望者）拆了 Muse 的对话界面，并点到豆包新推出的「小豆」。绝大多数 AI 对话仍是左侧头像紧跟气泡，Muse 借用了即时通讯里顶部居中的头像布局：横向阅读空间被释放出来，可爱的 IP 形象也可以把「正在工作」做成可视化状态，个人智能体的陪伴感更强。代价是纵向空间会占掉一些，读长文时这个动态形象还可能形成干扰。笔记写到，豆包小豆也采用了类似设计，并判断这有可能成为 Personal Agent 的一种通用界面范式。这条猎人笔记本身不长，没有展开交互细节或对照实验，但对做对话和 Agent 界面的人已经够用：头像从「消息发送者」变成「房间里的伙伴」，布局逻辑就不一样了。

顶部居中能强化陪伴感，也会占用纵向空间；如果主场景是读长文，动态 IP 是否一直待在视野里，值得单独做一次取舍。

把 Claude、GPT、Gemini 当成一个团队：中间那个位置，审美和双手都要在

优设网（昨天，11 月 24 日）数字生命卡兹克写了一篇约 28 分钟的调度长文。他给三个模型画了性格：Gemini 4 Neon 最好聊、文案和头脑风暴最灵，审美也拿得出手，但粗心、幻觉多，Antigravity 这套 Harness 目前最拖后腿；Claude（文中写到 Opus 5.5 与 Fable 5.2）沟通够用，审美是三家里最好的，前端、主视觉和剪辑里的大段视觉特效几乎都是代码直出，Claude Code 的工具调用也最顺手，毛病是改东西有时会漏、再加上经常不给你用；GPT-6.2 Astra 信息密度最高但最难读，审美偏弱，却最严谨，后端、查错、代码审查和操控浏览器他都交给它，缺点是过于听话，你写错了它也会照着错的执行。他的结构因此很简单：稍大的任务几乎只跟 Claude 说话，由它听懂需求、拆解，该自己干的自己干，该派给 GPT 或请教 Gemini 的再分出去，最后验收，再用听得懂的话回报；人只出现两次——说需求和拍板。中间这个位置之所以更想用 Claude，是因为它既要听懂说了一半的需求，又要把任务翻译成 GPT 能精确执行的指令，还得从 Gemini 那些自信满满的建议里挑出看走眼的部分，而 Gemini 最粗心、Harness 也最弱，不适合当总指挥。没有 Claude 时，他建议用 Gemini 4 Neon 顶上，效果会差一点，但差距没有想象中大。对设计师来说，这篇更有用的不是「三个模型排行」，而是分工：主视觉和动效可以更信 Claude 的审美，文案和点子交给 Gemini，细活和检查交给更严谨的那边。

与其等一个万能模型，不如先分清谁负责听懂你、谁负责想方案、谁负责把细节做完；中间那个位置，审美和执行都要在。

AI 工具与产品

新工具、产品动态与能力边界

商汤 SenseNova U1.6：先出一张，再对照提示把字和版式改对

IT之家（昨天，11 月 24 日 12:58，作者汪淼）报道商汤发布并开源 SenseNova U1.6 原生多模态模型。它延续 U 系列「理解和生成统一」的路子，第一次给该系列的 8B 开源模型加上原生图像自修正：打开之后，同一个模型会先出首稿，再对照原始提示检查画面，并针对发现的文字问题生成修正版。文章特别写到，人像光影、插画笔触，以及海报里字体和版式的配合，是这次打磨的细节。面向文字，U1.6 加强了透视字、艺术字等复杂表达，还引入了面向文字与布局的信息图美学模型，希望在把字写对的同时，保留字体表现力、空间透视和版面美感。它支持一次出图完成图文结合的海报，也能把艺术字、非常规字形和手写体当成画面里的创意元素。内部用户评测中，U1.6 Lite 的美学得分比 U1.5 Lite 高约 10%；在 UltraTextBench 密集信息图测试里，U1.6 Lite 从单次生成的 86.04 升至开启自修正后的 92.28，相对提升约 7%。模型权重已经开源，也可在商汤小浣熊、Seko、Kapi 相机、SenseNova Token Plan 和 SenseNova Studio 里体验，并且已上线 ComfyUI，能接到现有工作流里。开源地址：https://github.com/OpenSenseNova/SenseNova-U1。

海报和信息图最怕字错、版式散；「先出再改」把检查留在同一模型里，但最终仍要人看一眼文字和层级。

11 月设计周刊第二波：Figma Specs、Sketch 变体，以及 Canva 允许关掉 AI

优设网（昨天，11 月 24 日）张老三的「2026 年 11 月设计周刊第二波」整理了 15 条设计、AI、案例和资源。跟日常工作更近的几条是：Figma 展示了把 Specs 和 Figma Agent 放在同一画布的流程，需求文档、界面、交互和技术要求可以集中在一起，再由 Agent 整理实施计划；开源桌面工具 Onlook 能直接打开本地网页项目，在画布里改布局和样式，并结合 AI Coding Agent 开发；Sketch 发布 Ghent（2026.4），正式上线组件变体 Variants 和 Sections，并把 Symbols 更名为 Components。Google Labs 的 Stitch Loop 则尝试让 Agent 结合代码仓库和产品数据，去找性能、无障碍等问题并给出供人审核的改进方案，目前开放候补。Canva 新增了 AI 功能控制，允许隐藏部分生成式 AI，并减少对 AI 素材的推荐——在工具普遍加 AI 的时候，把选择权交回用户，本身也是一种体验设计。Nielsen Norman Group 的研究则提示：给 AI 的是整理过的研究结论，比直接喂原始评论更容易得到符合要求的方案，实验中平均评分标准满足率分别是 77.9% 和 69.5%。周刊后半还有 Interaction Library 这座「虚拟书架」交互作品集、几则品牌案例，以及 Google Noto Emoji 素材库；另外也提醒最近有人遇到 Figma 教育版文件被锁，需要及时转移到 Free 团队的 Drafts 并做本地备份。这是一辑盘点，不是单点实测，点进周刊里的原始链接看更新说明会更准确。

这一波里更值得收下的，是「把需求和设计放进同一块画布」，以及给团队一个关掉 AI 推荐的开关；研究结论要先整理，再拿去生成方案。
