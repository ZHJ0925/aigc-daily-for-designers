7 招摆脱「AI 味」UI：先线框与情绪板，再让模型临摹

优设 Clip 设计夹（昨天）整理 Vibe Coding 实操：纯文字常出蓝紫渐变 + Inter + Lucide 的模板脸。对策包括 Excalidraw 线框图喂结构、按组件截参考图、情绪板锁配色、先写 Design Tokens/CLAUDE.md、用禁止清单挡默认样式，以及换字体/图标库。核心一句话：别让 AI 想象，让它临摹。

项目开场先交「线框截图 + 色板 HEX + 禁止清单」三件套；组件级参考图比整页扔给模型更稳。

AI 个人网站：从构思、Pencil 到 Codex 部署的全流程

优设（昨天）从设计师视角复盘第三版个人站：ChatGPT 网页版做产品构思，Pencil 出设计稿，Codex 负责开发与动效并部署上线。强调有了 AI，对齐网格与细节可 100% 落到代码，不必再被「开发砍细节」；并对比作品集 PDF vs 个人网站的选择。

GrokBot 多 Bot 分工：设计师可抄的 Personal Agent 体系

优设阿真（昨天）分享两个月 GrokBot 用法：本质是 Personal Agent，可建多个独立 Bot 分工，并打通本地电脑。文内给入门技巧与多 Bot 协作示例，适合把需求 check、资料简报、日报等重复活拆成专用助手，而不是一个全能对话框硬扛。

按「一事一 Bot」拆职责（简报 / 需求 check / 素材整理），并在每个 Bot 简介里写清输入输出格式，减少串台。

国行 Apple 智能首发：Siri 灯效、实时翻译与千问联动

IT之家（今天）汇总 iOS 27.3 开发者预览为国行带来的「Apple 智能与 Siri」：长按电源键跑马灯呼出、信息/FaceTime/电话与 AirPods 实时翻译，以及 iPhone 联手千问扩展能力。面向 iPhone 15 Pro 及更新机型，是国行体验设计师需要立刻跟进的系统级入口变化。

车机/手机双语与面对面翻译场景，优先画「谁在听、字幕落点、打断恢复」；系统灯效是新的唤起反馈，别再只画旧波形。

纯语音 Personal Agent：边喝咖啡边派活，UI 也在线

量子位（昨天）体验一款审美在线的纯语音私人助理：可边听新闻边打断派任务（如回邮件），不陷入尴尬静默，体验被比作电影《Her》。作者强调它比一堆前沿 Demo 更贴近日常——语音连续性与「人味」打断恢复，是 Personal Agent 产品体验的关键课。

Kimi 游戏/创意方案：直连 Unity、虚幻与 Blender 工程

IT之家（昨天）介绍月之暗面面向游戏与创意的方案：基于 Kimi K3.1，配合 Kimi Code / Work Agent，经插件连接 Unity、虚幻、Blender 等，直接操作现有工程并交付可编辑文件与操作记录。目标是降低玩法原型验证成本，打通策划—程序—美术跨工具协作，而不是只吐一段说明或一张概念图。
