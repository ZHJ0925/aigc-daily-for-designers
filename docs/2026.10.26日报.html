58 组 AI 角色设定提示词：三视图到表情动作直接复制

优设阿真Irene（今天）整理 58 组可复用角色设定提示词：白底立绘/三视图/四视图、转面与八方向、表情六宫格、口型、手脚道具、动作分解，再到综合设定总表与机械/动物变体。用法是固定同一张清晰参考图 + 复制对应模板；常用推荐 03 号白底四视图与 47 号综合总表，模型侧建议 Image 2.5 或最新生图。作者强调连续出图时保持参考图、画风与版式一致，不需要图注时可删掉「小号中文说明」那句。

短剧/IP/吉祥物立项先建「身份四视图 + 表情卡」两张资产，再进视频模型；把提示词存成团队 Skill，比每次口头描述五官更稳。

一年省几千：PhotoCraft / ArtCraft / VoiceStudio 三款开源平替

优设 AI星踪岛（今天）盘点三款零订阅工具：PhotoCraft（getartcraft.com）可开 PSD，用 Claude Opus 重构了多款轻量创意/办公能力，适合应急修图但复杂稿仍会崩；ArtCraft 先在 2D/3D 里摆图层与机位再生成，减少「同提示词姿势全变」的抽卡浪费（软件免费，生成吃 Credits 或自备 API）；VoiceStudio 本地声音克隆与视频配音，带 MCP/本地 API，适合不想上云的长视频配音。文末另提 CleanYourTV 清安卓电视开机广告。

团队采购前先画「轻量修图 / 稳定构图 / 本地配音」三条线分别试一天；ArtCraft 把「机位与人偶」写成可复用场景模板，比堆提示词更省额度。

免费商用「嗷呜碎黑体」：破碎笔画撑起海报大标题

优设程远（今天）介绍基于械黑 GB 的「嗷呜碎黑体」：保留黑体厚实骨架，在结构里做斜切、缺口与错位，英文数字标点同气质，可免费商用。适合音乐节、街头运动、电竞等要态度的主标题；字越小、段落越长越伤阅读，正文/日期/地点应交给常规清晰字体。黑白或荧光绿等高对比配色更能放大字形张力。

标题字体选型清单：冲击力场景用「结构破碎」而非叠磨损纹理；混排时中文扛主标题、英文做短补句，并单独验收小字级可读性。

Kling 4.0 在 fal 向全量客户开放 API

fal（AI HOT · 10/23）宣布 Kling 4.0 正式向公众开放，所有客户可通过 API 访问。能力侧强调最长约 30 秒带音频的原生视频、最多 15 个图像/视频/元素参考、最多 10 个关键帧精确控制，并提升运动、角色一致性与电影感叙事。对需要把分镜、角色参考和关键帧写进流水线的设计/影像团队，API 比只在网页点生成更利于批处理与 Agent 调用。

把「参考素材上限 + 关键帧节点」写进分镜表字段，再交给 API；先用短镜头验角色一致性，再拉长到 30 秒，避免一上来烧满额度。
