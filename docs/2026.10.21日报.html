Tessl：PR 量翻四倍后，我们不再逐行审 AI 代码，改为验证意图

Tessl 工程博客（AI HOT · 10/19）：团队合并量约为一年前四倍、代码几乎全由 AI 生成后，放弃逐行 diff。改为在生成前审查意图与验收标准，用 offer-skill 等技能理解变更，并把仓库规则写成可自动校验的约束——把人的注意力从「这行写得对不对」挪到「要解决的问题对不对」。

和 Coding Agent 协作的设计稿交付，可先附一页「意图卡」：目标用户、成功标准、不可破坏的约束（组件/无障碍/品牌色）；让 Agent 与评审都对着同一张卡，而不是对着三千行 diff。

大厂 AI 场景

大厂产品与交互场景观察

微软 Guardian Agents × WPS Comate：Agent 代操作时，边界怎么设计进产品

极客公园（10/20）梳理企业办公里的新问题：屏幕上仍是员工账号，真正读写文件、外发内容的却是 Agent。微软推出 Guardian Agents 从外侧监控；金山 WPS Comate 则把会话、执行框架、OS 级沙箱与云端工作区做成四层解耦，高风险动作（删文件、发邮件、改配置）默认人工审批、超时拒绝，并为每个 Agent 注册可追溯身份。

设计「Agent 可代办」流程时，把不可逆操作做成结构化审批卡（一次性 / 本任务 / 限时 / 长期），并默认展示「它读了什么、将写到哪里」——比只在聊天里回一句「好的」更可追责。

Lovart 2.0 Arti：咖啡品牌 SLOWBEAT 从调研到开业物料的一镜到底

优设实测（约 15 小时前）：先聊风格并上传过往作品沉淀「记忆」，再把品牌定位一次性丢给个人设计 Agent Arti——它完成社区咖啡视觉调研、三版 Logo、字体配色延展，到门头/杯袋/徽章/开业海报；同事在画布批注后，Arti 汇总意见并一键改稿，还可把流程沉淀为 Skill、设置定时设计委托。

下次品牌延展别从空白对话开始：先喂 5–10 张「过往正稿 + 明确否决的版式」，再写清物料清单与比例约束；把人的时间留在定方向和终审，而不是反复重述审美。

Databricks MemCurrent：给生产 Agent 一套可读可写的持久记忆

Databricks 工程博客（AI HOT · 10/20）介绍 MemCurrent：面向生产 Agent 的持久记忆架构，结合情景记忆与派生记忆，通过插件、工具调用和离线 dreaming 管线三种模式读写整合；已支撑 Agent Bricks Memory 与 Genie，在内部记忆基准上同时优化通过率与每任务 Token。

设计/运营 Agent 若总「忘了品牌色和上次否决」，优先补「可引用的记忆条目」（偏好、度量定义、成功工作流），再堆更长上下文窗口——记忆比临时塞进 Prompt 的小说更稳。

Meshy Edit：圈选 + 一句话，做 3D 模型局部修改

量子位报道：Meshy 发布基于自研模型的 Meshy Edit——用套索/画笔选区（可覆盖正侧背），再用自然语言描述改动（可附最多 5 张参考图），约一分钟生成新模型且未选中区域保持原样；原模型保留，可继续编辑或送切片打印。已向全部注册用户开放。

产品/IP 三维资产迭代时，先固定整体再「只改帽子/只加工具」，比整模重抽更可控；把选区截图留进设计文档，方便和三维同事对齐改动范围。
