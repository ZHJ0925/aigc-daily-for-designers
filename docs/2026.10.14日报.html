AI 做网页总是蓝紫渐变？3 招摆脱千篇一律的模板感

作者拆解 AI 生成网页「长得都一样」的根源：「现代、专业」这类模糊指令会让模型回落到最安全的高频模式——蓝紫渐变、玻璃拟态、超大标题、三栏卡片。解法是补足产品语境（给谁用、要什么情绪）、明确列出「不要做什么」，再由人做最终取舍。

从 ToC 到 ToA：AI Agent 时代的产品设计方法

Ant Design 体验设计师元尧提出 ToA（To Agent）：产品同时要服务人类 UI 与 Agent 能力接口。交互从「用户点击 → 系统响应」变成「表达目标 → AI 规划执行 → 人审核接管」，设计重点转向委托体验、显性规则、自主权分级与可恢复的失败路径。

设计师的新职责是「权责设计」：把按钮背后的隐性规则写成 Agent 能读懂的契约，并让用户看得见 Agent 当前处于哪一级自主权。

AI 拿掉也成立的设计基本功

配图花 + 用色多 + 看着乱：书城界面怎么做视觉统一

以网文书城改稿为例，管理视觉复杂度抓三件事：色彩（主色只落在关键选中态，减少大面积渐变）、组件（避开异形轮廓与重特效）、配图（避开带标题的复杂海报，按题材选主体突出的图）。先填配图，再判断是否还需要加色。

内容型页面遵循「配图先行、UI 让位」：配图本身带色时，UI 用色越克制，整体越干净，这条规则对电商、资讯流同样适用。

Figma 轻拟态玻璃按钮：4 个细节做出通透高级感

从基础形状、透明度、背景模糊到描边与阴影，逐步拆解玻璃按钮的质感来源，重点在边缘高光与柔和阴影的微调；不依赖插件，App、网页与作品集展示都能直接用。
