HTML 取代 PPT？用 DeepSeek / Gemini + Skill 5 分钟出可编辑演示

优设（约 2 天内）跟着「HTML 要取代 PPT」试了一圈：同一套需求分别喂给 DeepSeek、GPT、Gemini，DeepSeek 中文观感更干净，Gemini 完成度高但信息易堆满。关键不是一句 Prompt，而是先写清受众与约束，再让模型预留可编辑区；进阶则安装歸藏 guizang-ppt-skill（杂志风/瑞士风），或把 styles.refero.design 的设计规范 .md 丢给 Gemini 统一视觉。作者强调 Skill=可复用操作指南，Prompt=单次对话。

周报/评审演示先定「可编辑 HTML」交付物，再装一份团队视觉 Skill；别指望一句 Prompt 出终稿——先对齐大纲与主题色，再让 Agent 按 Skill 落地。

设计周刊第二波：Figma Code Layers、Specs 与 Make 录制流程

优设周刊（约 2 天前）整理 Config India：Code Layers 公开测试，设计稿可转可交互代码原型，也能从 GitHub/本地/网页导入同屏对比；Figma Specs 给 Markdown、画面与技术细节共享空间，方便人与 Agent 共写需求；Make 接入 Payload 生成带 CMS/鉴权后台，并逐步提供 Gemini 4 Argon。「复制设计」入口挪到 Edit，还可 Record flow 把多页状态拷回 Design 图层（不带回交互）。同期收录 OpenPencil、PPT Lottie、Shotbase 等神器。

设计→原型评审时优先开 Code Layers/Specs：让 Agent 读同一份 Spec，少在聊天里贴截图；录制流程只当快照，别指望改 Design 自动回写 Make。

Aerial 爆改老电视：无广告网格桌面对标 Apple TV

优设（约 2 天前）介绍开源电视桌面 Aerial：砍掉推荐流，只留壁纸、时钟与规整应用网格，焦点浮起显示名称，内置航拍屏保并可扫码传相册。难点是厂商固件会抢回主页键——项目用默认桌面申请、守护与开机自启组合拳。作者给出 WorkBuddy 一句话安装提示词（读 agent.md 后本机跑 ADB），强调不卸载原厂桌面，随时可还原；另推 CleanYourTV 停用广告组件。

做客厅/大屏 UI：先砍信息噪音再谈动效；焦点态要放大+明示名称。用 Agent 装机时把「验收命令输出」写进 Prompt，避免只拿到步骤说明。

iPhone Duo 多屏体验：铰链、分屏、双窗口与外屏附件怎么拆

优设陈子木（约 2 天前）据 Tech Talk《Leverage multiple displays and scenes》梳理：铰链状态（合上/半开/展平）与连续角度分工不同——吉他摇把变调只在半开读角度，退出须归零；连续视听可用 onHingeChange，控件避折痕与主从排布必须交给 Reserved Regions 与 Arrangement，别按角度硬编码。分屏多任务与同应用多窗口要分开验收；外屏不能新建窗口；CameraCaptureAccessory 做提词器须内屏全屏+相机会话+相机视图可见，并把用户 enabled 与系统 availability 解耦。

折叠/双屏评审清单：动效生命周期、布局接口边界、分屏 vs 双窗口、附件三项前提——写进设计规格，比再加一屏「概念图」管用。

Replit Monitoring Agent：上线后自己查因、修、发版

Replit（AI HOT · 10/22）把 App Monitoring 闭环：Agent 可读生产日志与指标，告警后调查根因、验证修复并可选自动发布，再邮件汇报变更。面向个人开发者与小团队——以前「用户说挂了」才知道，现在发布设置里打开 alerts / auto-fix / auto-publish 即可。官方把它放进「自主软件团队」叙事：从写代码扩展到值守与修复。

设计侧搭内部工具/小程序时，把「监控开关与自动发布权限」做成设置页一等公民；自动修要默认可关，并强制留下可读的变更摘要给人类复核。

OpenAI Decisions API：给实时交互做低延迟微决策

OpenAI（AI HOT · 10/22）正式推出 Decisions API（GPT-6 Luna）：面向分类、路由、打分等有界答案，比 Responses 路径可快一个数量级。支持 predicate/choice/score，单请求最多 400 题，可接图与 JSON；并与 GPT-Live 原生联动——演示里根据用户话语为虚拟形象选表情。Box、Datadog、Sierra、Speak 等用它做单据路由、风险评分、客服下一步与语言学习打断。

做语音助手/数字人/客服流时，把「下一步动作、表情、是否追问」拆成 Decisions 问题清单，而不是整段自由生成；UI 上同步展示「正在判定」比干等更稳。

MOSS-Image：开源 5B 生图，用 JSON Layout 卡住海报排版

量子位（10/23）报道模思智能/OpenMOSS 开源 MOSS-Image：强调去掉 AI 生成图训练以减轻「同质 AI 味」，上线数日海外下载破百万。对设计更关键的是中英密集文字、JSON Layout + Bounding Box 控位，以及最长约 4096 token 条件；社区已出 4/8 步加速、量化与各类 LoRA，并有 Prompt Enhancer Skill。文章也提 API 与桌面助手 MosMos。

电商主图/信息海报优先试「summary + items + bbox」结构化出图，少把整页构图押在一句自然语言；复杂稿再叠团队 LoRA 稳风格。

Kimi K3.1 Pro：草图/参考图直出可编辑 3D，网页端上线 3D Make

Seedance 2.5 4K：先 480P 样片打磨分镜，再出大荧幕正片

极客公园早知道（10/24）记火山引擎发布 Seedance 2.5 4K：强化表情、微动作与纹理轮廓，10-bit 色深；支持 Draft 模式先用 480P 低成本验证分镜与镜头，确认后再生成 4K。目前 4K 定向邀请约 20 家影视工作室/导演做剧集与电影前期。同日亦见 Kimi 3D、iPhone Duo 交付等速览。
