SenseNova 6.8 Flash：网页 / 动态 PPT / 海报可直接验收

HomeView OS：无 App Store，CarPlay 模板成临时桥梁

IT之家（今天）据 AppleInsider：苹果智能家居中枢 HomeView 系统高度封闭，无 App Store、不可自装第三方应用。系统疑似基于 tvOS 27.2，启动器 BreadBoard、控制中心 CupBoard；应用运行大量借用 CarPlay API（内部称 PebblePlay）——开发者交模板、系统负责渲染，目前偏音频/视频，导航与聊天类受限。

做家庭共享屏体验时，按「模板化界面 + 系统渲染」而不是完整 App 来画信息架构；优先音频/视频与家庭控制场景，别假设可自由分发。

阿里云 Memory：Personal Agent 的长期记忆与 MCP 接入

IT之家（昨天）报道阿里云 Memory 服务升级：从对话提取偏好、计划与约定写入画像，后续会话检索进上下文，减少重复询问；支持自定义记忆规则与控制台调试。可通过 API，以及 MCP/CLI 接入 Codex、DeepSeek Harness、Claude Code、OpenClaw 等。HaluMem 与 PersonaMem-v2 评测多项靠前。

设计「个人助理」时把可写入记忆字段（偏好/期限/禁忌）做成可审查列表；偏好变更必须二次确认再覆盖。

腾讯混元 Hyra 2.0：科研 Agent 从刷题转向造可复用工具

IT之家（昨天）报道混元 Hyra 2.0：研发重点转向让通用 Agent 参与模型、工作流与软件工具升级，一次成果可反复复用。架构分 Overall（对齐人类目标）、Mission（长期问题与路线）、Worker（实验与质疑）；项目状态、分层记忆与共享知识库 Books 分离，复盘可沉淀可迁移 skill。

沃顿教授：审美判断力等四类能力，比「转行技工」更抗冲击

IT之家（昨天）摘 Ethan Mollick《共存》观点：大模型迭代快，「学会用 AI」或躲进纯动手岗位都不够。他提四种特质——深度专业认知、广博知识面、审美判断力、主观能动性；并提醒学徒制崩塌后新人难攒阅历。提示词越来越像项目管理：定义需求、验收标准与分阶段交付。

周会可用四类能力做自我盘点；带教时把「验收标准与多方案挑选」练成固定作业，而不是只教快捷键。

小城拉风体：右倾尖角标题字，海报自带速度感

优设字体猎人（2天前）推荐免费商用「小城拉风体」：粗重轮廓右倾、边缘密集尖角并留细小白隙，短句标题自带出发与街头动势。适合封面与活动主视觉大字；小字号细节易糊，日期地址宜配常规正文字体。留足主标题周围空间，尖角与白隙才看得见。

运动/街头向项目字库备一款倾斜标题体；终稿检查小字是否改用无装饰字体，避免尖角挤成一团。
