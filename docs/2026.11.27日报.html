大厂 AI 场景

大厂产品里的设计信号

淘宝设计把规范收成 Skill：4 个页面，从约 4 天跑到约 3 小时

优设网（昨天，11 月 26 日）淘宝设计团队写了他们跑通的「设计到开发」链路。过去设计师按规范手工搭稿，再交给前端还原，中间最常见的两个问题是重复劳动和规范走样。他们把设计规范、组件资产和业务规则沉淀成「设计 Skill」，让 AI 每次生成时主动加载并遵守这些规则，设计师转向定义规则、描述目标、判断质量和持续校准。主线是：设计资产 → 设计 Skill → AI 生成 HTML UI 原型 → 回流成可编辑设计稿，或转译成符合目标代码库的工程组件，再部署到预发。HTML 原型是枢纽：它不是一张死图，而是可以继续流转的中间产物。Skill 大致分三层：做路由的主文件、规范知识层，以及可执行脚本与素材。从零搭建可以拆成五步：喂原料、搭初版、增补规范层、按导航和结算栏等逐项验证，再对还原不准的地方系统性补规范。踩坑后的硬规则包括：基础规范一律走 token、禁止写死色值；间距和圆角限定在预设梯度内；新规范必须回写到资产文件，否则换个会话就丢了。生成时用「做设计稿的思维」把结构、尺寸、间距和信息层级说清楚，还可以一次出两个对比方案。往下游走时，编码规则不是人工预设，而是 AI 从现有代码库里学到的。小范围试点覆盖 4 个页面、1 名设计师，时间计入全链路，返工和二次校对也算进「AI 方式」：传统「设计—开发—验收」约 4 天被压缩到约 3 小时，大约 15 倍，样式验收提升最明显，因为代码天然符合 token。他们也划了边界：token 体系越完善、组件复用率越高、团队越大，收益越明显；尚在建设期、规范未收敛的应先收敛规范；纯创意类、无法量化为 token 的视觉设计，并不适合这套方法。

先把规范写成 AI 每次都会加载的规则，走查才会从「事后改」变成「生成时就不偏」；规范没收敛时，先别急着上全链路。

Agent 与编程实战

Agent 工作流、协同与开发向实践

先用视频定视觉，或先用代码排动作：MAGI-2 和 Neon 的双向玩法

优设网（昨天，11 月 26 日）歸藏写了一套把谷歌 Neon 和国产视频模型 MAGI-2 接在一起的玩法。卡兹克、阿真等人已经测过 MAGI-2 的短剧和表演，他这边更关心 Agent 和视频模型能怎么配合。MAGI-2 支持 30 秒 1080P、多图多参混合参考，也吃得下最长约 2 万字的提示词；标价 1080P 每秒 0.5 元，文中提到 LibTV 限时特惠可到每秒 5 分。他先做了几项基础测试：敦煌飞天的大幅度旋转和飘带比较稳，竹林武侠的跟拍运镜不错；还拿一张带色块滑块的 UI 图生成视频，滑块滑到对应色板时场景会跟着变色，说明模型能理解这种逻辑。咖啡店视频里吐小票、盖章和点屏幕时的文字，也少见常见的果冻感和伪影。问题主要有两个：提示词润色有时会偏，音频里背景音乐和动作音效常常只能出来一个。真正要分享的是两套流程。Video to Code：先在 LibTV 用六宫格分镜喂给 MAGI-2 做出一段带图形、飘带和连续转场的视频，再让 Neon 读取配色和动势，写成一镜到底的视差滚动产品官网。他觉得这种滚动中持续变化的效果，只靠提示词让 AI 直接写代码很难一次写好；有了视频当视觉参考，第一版就比较能用，后面只微调了字体排版和个别动画闪烁。MAGI-2 出的视频往往只有音效没有音乐，他还让 Neon 用代码生成电子乐，并把 BPM 跟页面滚动速度连上。Code to Video 则反过来：先让 Neon 写代码生成一段 2D 横版 Boss 战的动作灰盒（跳跃、弹反、顿帧、镜头特写和连招位置），不要带音频以免干扰参考；再在 LibTV 画布里用全能参考，把设定图和这段代码视频合在一起，生成水墨风格的打斗成片。动作不满意就改代码，比一次次重新抽卡更可控，素材也可以复用。他把 MAGI-2 提示词优化方法、LibTV MCP 在 Antigravity 上的适配修复，以及这两套工作流打包进开源 Skill：github.com/op7418/guizang-magi2-skill，装上后可以让 Agent 直接调用。

视频便宜了以后，不一定要直接「一句话出成片」；用视频当视觉稿，或用代码当动作稿，往往比纯抽卡更稳。

Claude 可以把做好的小工具，安装成 Mac 和 Windows 桌面上的独立应用

IT之家（前天，11 月 25 日 7:17）报道，Anthropic 为 Claude 的交互式 Artifacts 推出了「安装为应用」（Install as app）。生成出来的应用可以安装到 macOS 和 Windows 桌面，拥有独立的工具栏图标，使用体验接近把网页应用装到电脑上，不必每次再从浏览器标签页里翻出来。权限上可以选默认模式，让它像普通浏览器标签那样运行；也可以额外允许发送通知、拦截键盘快捷键，以及显示在其他窗口之上。还可以授予完整的计算机访问权限，不同权限会影响它能调用的系统功能和可执行的操作。该功能目前处于 Beta，正在向 Mac 和 Windows 桌面用户逐步开放。对设计师来说，如果经常用 Claude 做出可点的原型、对照工具或小面板，装到桌面后更方便反复打开和演示，而不必依赖某一条聊天记录。

把生成结果留在桌面图标里，比把它埋在聊天记录里，更接近「这个工具我以后还要用」。
