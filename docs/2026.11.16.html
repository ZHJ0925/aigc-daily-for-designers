别再堆「8K、杰作」了：8 个能提高生图质感的提示词写法

优设（今天）AI星踪岛把 2026 年还在用的「大师级、高级感、8K、Octane」判成基本白写，并整理了 8 个实测过的新写法。想要照片质感，就写材质、光线、镜头焦段和构图，而不是给画面贴奖状；需求已经明确时，把颜色、圆角、字号和网格写成设计规范，「高级感」三个字模型并不知道该执行哪一条。做海报时用视觉层级和留白，例如 60-30-10，只留一个主焦点，避免四周塞满发光装饰。写文案时不要先给模型抬轿子，直接交代受众和具体特点。如果不会写提示词，可以先让它来问你。电商主图里，玻璃瓶要靠柔光箱、轮廓光和合适的光圈，而不是再堆「奢华、8K」；人物要写进褶皱、毛孔、碎发这些真实痕迹，才能去掉那层硅胶感。卖点也不要一次塞进一张九宫格，更好的办法是一个视觉锤配几个数据卡。每条都配了反例和改写，方便对照。

少写「高级感、8K、杰作」，多写材质、光线、镜头和规范；真要控制风格，就把颜色、字号和留白写成规则，比空喊高级更稳。

AI 做网页动效，怎样既好看又不卡？先收好这 3 个 Skill

优设（今天）程远拿一张课程报名页举例，把网页动效拆成三件事：选合适的效果、让操作跟手、以及排查掉帧。Transitions.dev 把常见的卡片展开、弹窗和提交反馈整理成可复用的 CSS 片段，Skill 说明里目前是 32 套，并且已经处理了 prefers-reduced-motion；作者提醒，官网上展示的 43+ 种动效和 Skill 已收录的数量不是一回事，网站也有付费项目，用前要看清授权。Apple Design 是设计工程师 Emil Kowalski 做的社区 Skill，不是 Apple 官方发布，重点是反馈要及时、拖动要跟手、动画要能被中途打断，并解释了弹簧、阻尼和速度传递，适合做移动端抽屉。Animation Performance 则专门诊断卡顿：优先动 transform 和 opacity，尽量避免每帧改 width、height、top，并且必须在真实手机上测，不能只看自己的电脑。三个 Skill 不是一条自动流水线，而是按阶段给 Agent 不同的方法。

先用 Transitions.dev 统一常见转场；手势跟手时再把「可中断、要跟手」写成给 AI 的规则；掉帧时去查动了什么属性，而不是只说「再优化一下」。

把 AI 塞进会议里：Claude Meetings 能当场搭白板、归类便签

优设猎人（昨天）龙爪槐守望者关注到 Claude 新出的 Meetings 功能。现在不少会议工具已经能会后做 AI 总结，但这次的思路更往前一步：AI 可以直接加入会议，听到团队提出需求后，当场建立白板，把散落的想法写成便签并归类整理；被直接提问时，也能在会议中回应；会议结束后再输出纪要。作者的判断是，与其等散会后让 AI 去做事后总结，不如让它现场充当随叫随到的白板执行员，既少掉会后整理的时间，也让模型更自然地进入团队协作的核心环节。

设计师必须学会写代码？Claude 设计负责人给出 6 个判断

优设（今天）觉之设计整理了 Claude 应用设计负责人 Meaghan Choi 在《Design Will Never Be The Same》演讲里的 6 个观点。她认为设计师会写代码已经是职责的一部分，争论本身意义不大；试新想法几乎不花成本，但「idea slop」也变多了，真正难的是判断什么值得做、做到什么程度可以拿出去。静态稿和不能用的漂亮原型，价值不如一个哪怕难看但真能跑的东西。Claude Design 最早来自一周后就下线的 Imagine Demo，设计师 Nate 把它改成能读取设计系统的前端原型 Skill，后来又接上品牌规范和幻灯片，一路都是设计师在做产品决策。Anthropic 的设计师向生产环境提交代码已经是常态，「有没有做完」也变成设计要定义的事：给出时间预估、控制范围、说明完成标准。她不愿意空谈「品味」，而把独有价值说成四项：创造性解决问题、化繁为简、端到端一致性，以及 fit and finish 的细节打磨。问答里她还说，不是每个人都该站在最前沿，如果不感兴趣，可以等三四个月、等工具更稳再上手。

写代码是为了让设计真正跑起来，并自己判断「做到哪算完」；点子已经不缺，更要紧的是判断什么该做、什么可以先不做。

芝士奶盖乌龙宋：圆润厚实的开源宋体，更适合做标题

优设（昨天）字体猎人介绍了墨豹堂发布的开源字体「芝士奶盖乌龙宋」，遵循 SIL Open Font License 1.1，样张基于官方 V0.103 轻便版 Bold 实际排印。它保留了宋体横细竖粗的对比，但把收笔和转折做圆，看起来厚实、有亲和力，又不会糊成普通圆黑体。作者认为它更适合把字号拉大做主标题，配料表、地址或大段说明还是交给常规无衬线体。文中试了四个高频场景：茶饮杯身字数要少、烘焙礼盒适合拉开字号对比、门店菜单要保证远距离能看清、甜品活动卡可以排得更松快。官方分完整版和轻便版，轻便版体积小，但遇到生僻字、人名或繁体应改用完整版。授权允许个人和商业项目免费使用，不能把字体文件单独拿去倒卖，用它做出来的海报和包装版权归设计者自己。整篇去掉下载区，字体判断本身仍然成立。

适合当包装、菜单和海报的主标题，不适合硬扛长段正文；用进设计稿前，先把全套真实文案敲一遍，确认轻便版有没有缺字。

LobsterAI 团队版：不收席位费，全组共用一个积分池

优设行业稿（前天）介绍了网易有道开源桌面 Agent LobsterAI 的团队版。作者的使用场景很具体：按人头买企业席位，用量不均的人会浪费，刚买完就离职又得再买一份；团队版改成零席位费，充进去的钱用在 Token 上，全组共用一个积分池，后台能看谁用得多，积分按称 365 天有效、不会跟月底清零。文中说开通门槛是 300 元。安全性上，日常会话、产出文件和环境配置保存在本地硬盘，删除本地文件、执行终端命令或发起联网会先弹出确认；也可以换成本地模型处理不适合上传的资料，并基于开源代码做私有部署。设计同事可以用其中的 Seedream、Seedance、MiniMax 等模型，也允许接入已有的 API Key。作者把它定位为 20 人以内小团队的办公 Agent，并提醒几百人的大团队若要深度定制，这套轻量方案不一定合适。这是一篇偏推荐的行业稿，关键信息可以核对官网和后台，不必照单全收。

人少、用量不均时，按实际消耗共用积分池会比按人头买席位更好管；涉及本地文件和命令时，先确认它会不会弹出确认，再决定能不能在工位电脑上放开手脚。
