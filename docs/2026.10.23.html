地理杂志风修图：保留原片，用透明地图做旅行大片

优设 9 图（约 2 天内）给出一套可直接复制的 Prompt：上传风景照后，要求完整保留原人物/建筑/光影，不整张重绘；在天空、海面等负空间叠透明地图（海岸线、等高线、步道），占比约 15%–25%，细线低饱和、少量英文地名，小红点标大致区位，保留原画幅与轻微纸质感。核心是「地图只做辅助图层」，避免方形地图卡片和大标题装饰。

下次出旅拍/地理专题 KV：先锁定「不重绘主体」这条硬约束，再让模型只在负空间补地图；没有精确 GPS 就只标区域，别伪造坐标——评审会更信。

豆包工作「无限画布」：双十一海报到电商详情一屏跑通

优设（约半天内）实测字节豆包工作新画布：接入 Seedream 5.0 Flash 与 Seedance 2.5，把调研、出图、涂抹精修、版本并排对比放在同一画布。文中演示双十一开屏、蓝牙耳机从用户提问洞察到详情分屏、以及小鸡吉祥物三视图+物料延展再到短视频——强调少在聊天记录里翻旧方案，多在画布上并排决策。

美团酒店「真·便宜」盲盒：把信息遮蔽做成让利互动

优设细节猎人（约 1 天内）拆解特价房详情页：隐藏酒店名、精确门牌与门脸图，保留房型硬参数与退改权益，用不确定性挡住跨 App 比价。背后是单体酒店挂牌价盘与渠道冲突——明码深折会击穿日常价，盲盒把闲置库存包装成趣味让利。

做「信息不对称」玩法时，先列必须透明的底线（价格构成、退改、硬性房型），再决定藏什么；趣味包装不能盖住履约风险，否则信任一次就崩。

35 万个 AI 去骗骗子：善意也能被规模化复制

优设（约 2 天前）讲述澳大利亚 Apate.ai：用带性格口音的 AI 假扮受害者缠住诈骗电话，耗掉骗子约 17 年通话时间，电信转接近 59 万通可疑来电，合作银行诈骗损失报告下降 76%。对照国内年轻人用 AI 反制「小海」卖惨带货——把善意做成可复制的对抗产品，而不只是个人英雄主义。

Anthropic：何时该把子 Agent 折回主循环

Claude 官方指南（AI HOT · 10/22）：企业常把组织架构复制成上百个子 Agent，结果上下文丢失、Frankenprompt、延迟翻倍。对比显示「单 Agent + Skills 渐进披露」往往在质量、成本与时延上更好。子 Agent 仍适合验证、真并行、权限隔离；其余优先折成 Skill/工具，并用端到端评测决定留不留。

设计侧搭「调研 Agent / 出图 Agent / 走查 Agent」前先问：它们是共享同一套品牌上下文，还是可丢弃的并行支线？能共享就折回主循环，只给独立调研留子 Agent。

MiniMax Code Mini App：让 Agent 干活停在常驻页面上

MiniMax（AI HOT · 10/22）给桌面端 Code 加上 Mini App：带前端+Node 后端的长运行插件，页在侧栏可弹出，Agent 与页面互相调用；宿主管端口、鉴权与回滚发布。可用 /miniapp-creator 一句话生成，官方示例含股票看板、CadQuery 标注回传、自驾路线规划，以及本身也是 Mini App 的 MiniMax Bot。

别把设计评审看板只生成一次 HTML：做成 Mini App（或同类常驻页），让改稿、标注、回传都留在同一界面，对话只负责触发而不是当唯一存档。

设计基础干货

拿掉 AI 依然成立的设计基础

作品集排版四坑：常规、太散、抢戏、太糊

优设（约 2 天前）用真实案例改作品集页：并排两屏太常规就放大视觉爆点；装饰英文太多就改「功能图标+卡片」聚焦；颜色规范页别让毛玻璃抢走权重信息；背景与卡片对比不够会显糊——加深背景层次、按大小节奏排卡片。原则仍是作品优先、30 秒抓住亮点。

改作品集前先截一页问三个问题：焦点是不是作品本身？规范信息有没有被装饰压住？背景和内容的对比够不够——比换字体更管用。

极客公园：Claude Duet 的克制，会是 Personal AI 的优势吗？

极客公园（10/22）把 Duet 放进 Grok Bot / Muse / Dots 对照：不实时狂扫、数小时巡检一次；发消息/付款/签文件/删除必须批准，证券交易与转账即便授权也不做；放弃生活化卡通叙事，只服务事务过载的专业人士与小老板。文中也引 Claire Vo「个人 Agent 疲劳」——主动却不推、独立 App 反而多一项待办。

设计主动助手时，把「何时闭嘴、何事必须人点头」写成产品规格，而不是上线后再加开关；入口尽量嵌进现有工作流，避免再开一个审批 App。
