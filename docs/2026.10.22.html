作品集里的 AI 人物太假？用插画风格避开「恐怖谷」

优设（约 8 小时前）指出：作品集里大量 AI 真人/3D 人物容易一眼假、还踩恐怖谷；影棚硬光、过度锐化、极繁国潮装饰在专业评审里常被当成「土味」。更稳妥的路径是先建立「简约、冷静、留一点缺陷」的素材观，找不到好的摄影/3D 效果时，改用有手绘感的插画映射形象，先找差异化参考再让 AI 按动作重画，避免封面跟风。

下次做作品集封面前，先翻 20 份初级作品集封面，把「一看就是 AI 网红脸」的套路列进黑名单；主体优先选「别人作品集里少见的插画语言」，而不是最完美的五官。

Tessl：编程 Agent 越来越多，陪护人不够用了

Tessl 博客（AI HOT · 10/21，引用 Jellyfish 数据）：中位公司已有约 22% 合并 PR 由自主编码 Agent 撰写（90 分位达 53%），但 Agent 独立审并结合仅约 0.6%。结果是上游写码加速、下游评审成为硬瓶颈，Agent PR 废弃率更高、人均审查负担上升。领先团队靠路由低风险任务、沙箱与大量自动化测试加速「可信任」而不是盲目放开合并。

设计侧若也在用 Coding/设计 Agent 出稿：把「可自动验收」的规则（组件 Key、间距、无障碍对比度、品牌色）写成可跑检查，人只盯意图与体验判断——陪护精力要花在刀刃上。

作品集用 PDF 还是个人网站？现阶段仍建议 PDF 优先

优设（约 7 小时前）回顾作品集载体变迁：PDF 在通用性、转发留档与「从上滚到下」的阅读效率上仍占优；个人站优势主要是交互与动效，但部署、访问稳定性与观看成本会直接拉低 HR/面试官体验。结论：先落地 PDF，再把网页当长期打磨的补充；国内访问稳定性优先于海外免费托管。

本周先保证一份「下载即看完」的 PDF；个人站若要做，把部署与域名当成交付的一部分，而不是做完页面就停——否则不如把时间花在项目包装质量上。

iPhone Duo 内屏自适应：避开折痕，用保留区域与 Arrangement

优设（约 24 小时前）翻译整理 Apple 设计/工程分享：半折时中央弯折为保留区域，居中照片与上下文菜单需成组位移；提示框随手持/桌面支撑姿态换位；双列列表落在折痕两侧，卡片网格加大中央 gutter。自定义界面读 Reserved Regions；主次双视图用 Arrangement（split/overlay）随尺寸类切换。

折叠适配检查清单可以很具体：展平/书本半折/桌面支撑各走一遍——菜单是否还贴着操作对象、搜索框是否还锚在对应列表上、自定义网格是否读了分割区域。

Anthropic Claude Duet：会主动找你的办公 Agent 研究预览

优设情报今日观察对应 OpenAI 帮助文档：Pro/Business/Enterprise（需 Space）可创建可编辑幻灯片，直接改文字/图/表，邀请同事实时共编与评论，并用 @ChatGPT 按反馈改内容与版式；网页可导出 PowerPoint、PDF 或 Google Slides。功能仍在灰度，未看到入口可能是账号尚未开放。
